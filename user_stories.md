# Smart Clinic Management System - User Stories

## 🧑‍⚕️ Doctor

- As a doctor, I want to log in securely so that I can access my dashboard.
- As a doctor, I want to view my scheduled appointments so I can manage my time effectively.
- As a doctor, I want to view patient medical history so I can provide better treatment.
- As a doctor, I want to update patient diagnosis and prescriptions after consultation.
- As a doctor, I want to manage my availability so patients can book accordingly.

---

## 🧑‍💻 Patient

- As a patient, I want to register and log in so I can use the system.
- As a patient, I want to search for doctors so I can choose the right specialist.
- As a patient, I want to book appointments online to avoid waiting in queues.
- As a patient, I want to view my appointment history and prescriptions.
- As a patient, I want to receive confirmation of my appointments.

---

## 🏥 Admin

- As an admin, I want to manage doctor accounts so I can control system access.
- As an admin, I want to manage patient records to maintain system data.
- As an admin, I want to approve or reject doctor registrations.
- As an admin, I want to monitor all appointments in the system.
- As an admin, I want to generate reports of system usage.

---

## 📌 Notes

- This document defines user stories for the Smart Clinic Management System.
- It follows role-based access: Doctor, Patient, and Admin.
